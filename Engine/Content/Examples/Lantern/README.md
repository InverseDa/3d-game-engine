The pinned `.gltf` still describes the original roughness, normal and emissive maps. The sample includes the Base Color image used by the static importer. It keeps the source document's exact bytes for the manifest digest.

`PreviewRig.json` adds a placement parent, a ground plane, a camera and a directional light. The imported root `0694e55a-83ec-48fe-848b-b73a76ff0104` is a convenient entity to move when checking F5 and the ground shadow.
